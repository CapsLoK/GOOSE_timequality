# Wireshark GOOSE TimeQuality Decoder (IEC 61850)

## 📖 Описание

`iec61850_timequality.lua` — это плагин (пост-диссектор) для Wireshark, предназначенный для глубокого анализа качества времени (**TimeQuality**) в сообщениях GOOSE по стандарту **IEC 61850**.

Стандартный диссектор Wireshark отображает временную метку GOOSE, но не детализирует статус синхронизации часов. Данный скрипт автоматически извлекает 8-й байт (`TimeQuality`) из поля временной метки (`goose.t`), декодирует его битовые флаги и выводит информацию о состоянии часов передающего устройства прямо в интерфейс Wireshark.

---

## ✨ Возможности

- 🔍 **Автоматическое извлечение** — считывает байт `TimeQuality` из временной метки GOOSE без необходимости ручной разборки пакетов.
- 🧩 **Декодирование статусов** — отображает состояние флагов `LeapSecondsKnown`, `ClockFailure` и `ClockNotSynchronized`.
- 🎯 **Анализ точности** — показывает числовое значение точности времени (`TimeAccuracy`, биты 0–4).
- ⚠️ **Визуальные маркеры** — добавляет предупреждения прямо в колонку **Info** списка пакетов (например, `[CLK NOT SYNC]` или `[CLK FAILURE]`), что позволяет мгновенно находить проблемные кадры в длинных захватах.

## 🛠️ Установка (Windows)

Для работы плагина вам понадобится Wireshark с поддержкой Lua (включена по умолчанию в стандартных сборках).

1. Откройте проводник Windows и перейдите в папку пользовательских плагинов Wireshark. Вставьте следующий путь в адресную строку:

   ```text
   %APPDATA%\Wireshark\plugins
   ```

   > Обычно это: `C:\Users\<ВашеИмя>\AppData\Roaming\Wireshark\plugins`
   >
   > **Примечание:** если папки `plugins` нет — создайте её вручную.

2. Скопируйте файл `iec61850_timequality.lua` в эту директорию.
3. Полностью закройте Wireshark и запустите его заново.

> 💡 Проверить, что Lua-скрипты загружены, можно через меню:  
> **Help → About Wireshark → Folders → Personal Lua Plugins**

## 🚀 Использование

После установки плагин работает в фоновом режиме и не требует дополнительного вызова.

### 1. Просмотр в списке пакетов (Packet List)

Откройте файл захвата (`.pcap` / `.pcapng`), содержащий GOOSE-сообщения. Обратите внимание на колонку **Info**:

- Если часы устройства не синхронизированы, в конце строки появится маркер:  
  `[CLK NOT SYNC]`
- Если зафиксирован сбой часов, появится маркер:  
  `[CLK FAILURE]`

### 2. Детальный разбор (Packet Details)

1. Выберите интересующий GOOSE-пакет.
2. В окне **Packet Details** (нижняя панель) найдите и раскройте протокол **GOOSE TimeQuality Decoder**.
3. В этом поддереве вы увидите:
   - Сырое значение байта в HEX (например, `TimeQuality: 0x20`).
   - Расшифровку каждого бита (`True` / `False`).
   - Числовое значение точности (`TimeAccuracy`).

### 3. Фильтрация

Плагин не регистрирует собственные поля для фильтрации, поэтому для поиска GOOSE-пакетов используйте стандартные фильтры Wireshark:

```text
goose
```

Для быстрого поиска пакетов с рассинхронизацией часов используйте поиск по тексту:

```text
goose && frame contains "CLK NOT SYNC"
```

## 🔬 Техническая справка: формат байта TimeQuality

Согласно профилю IEC 61850, последний (8-й) байт временной метки имеет следующую битовую структуру:

| Бит   | Название                 | Описание                                                                 |
| :---- | :----------------------- | :----------------------------------------------------------------------- |
| **7** | `LeapSecondsKnown`       | Известно ли количество високосных секунд (`1` = True, `0` = False).      |
| **6** | `ClockFailure`           | Зафиксирован ли сбой часов (`1` = True, `0` = False).                    |
| **5** | `ClockNotSynchronized`   | Рассинхронизированы ли часы (`1` = True, `0` = False).                   |
| **0–4** | `TimeAccuracy`         | Значение точности времени (0–31), кодирует класс точности по IEC 61850.  |
